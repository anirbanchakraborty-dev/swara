# Swara

Swara is a fast LilyPond toolkit for Neovim, built from the ground up: a new Tree-sitter grammar for LilyPond, a language server written in Rust that checks a score each time typing pauses, and a Neovim plugin that wires both in, opens the PDF in Skim, previews and plays a score, and creates guitar, piano and song lessons that print Indian sargam names and Bengali lyrics. Status: in development.
